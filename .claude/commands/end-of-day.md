---
description: Close the day: log every leg flown, record duties and complete the trips
---

Run `to-log --json`. For each leg ask for, or read from the pilot's journey log the operator pastes, the block and air times, landings and fuel, and run `/fly`. Record each pilot's duty with `/duty`, then `/complete` each trip whose legs are all logged. Finish with `crew-check`.

Ambiguous names list the candidates and stop: ask which one. Never send anything; drafts stay in `drafts/`.
